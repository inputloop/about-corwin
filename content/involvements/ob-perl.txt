== summary ==
Org mode lets you keep runnable code blocks inside a plain text document, and each language has a small file that knows how to run it. I look after the one for Perl.

== function ==
Maintaining it means answering bug reports, reviewing patches, and keeping its behaviour in step with the rest of Babel. I took it on in December 2020 when the Org maintainers asked for a volunteer.

== practice ==
It is a small job on purpose. Free software keeps going when a lot of people each hold one piece they understand well.
