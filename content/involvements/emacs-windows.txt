== summary ==
When a new Emacs release comes out, someone has to turn the source tarball into an installer and zip files that a Windows user can download from the GNU mirrors. For the past several years that has been me, as a volunteer.

== function ==
The work is mostly careful repetition: build the release tarball and the development branch with the same toolchain, make the self-installer with the NSIS script that lives in the Emacs tree, and publish the binaries together with the sources they came from so that anyone who gets one can get the other.

== practice ==
I gave a talk about it at EmacsConf 2023, Windows into Freedom: a short history of the Windows port, how to get the binaries, how a Windows build differs from other platforms, how to make the installer, what the GPL asks of anyone who shares binaries, and the scripts that let a build track a branch. The point of the talk was that none of this needs to be one person's secret.
