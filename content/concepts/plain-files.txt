== summary ==
Memory, catalogs, ways of working and this page's content are all text files. You can read them, diff them, keep them in git, and carry them to another program without asking us.

== function ==
A plain file is the cheapest way to keep the right to leave. If our tool goes away, the notes do not go with it.

== practice ==
This site is built from one text file per card. The build turns them into the page and into the index the prompt searches; nothing else holds the content.

== presentation ==
The window types a plain text file into an Emacs buffer.
