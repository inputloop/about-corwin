== summary ==
When two representations of one truth can split silently, one reader is not evidence. A second reader, written in a different language by a different route, catches what the first one shares with its own mistakes.

== function ==
The shop's page is written by one tool and read back by another. On this site, the browser code computes how tags relate, and a Python test recomputes the same numbers from scratch and compares.

== practice ==
It costs a little more to write. It costs much less than trusting a green light that could never have been red.
