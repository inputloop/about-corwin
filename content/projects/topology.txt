== summary ==
draw reads the git repositories you keep. Each one can say what it is in a short file called TOPOLOGY.md; draw sorts what they say by place, part, path and person, and draws the result so you can move the shapes around.

== function ==
The browser app works with no server at all: what you draw stays in your browser. A server is optional, and every feature on it can be switched off. Parts a repository marks private stay hidden until its owner says to show them, and the drawing says that something is being kept back.

== practice ==
It is a working branch, one of several versions made from the same conversations to be compared later, and nobody outside the shop has reviewed it. Its own README is the place to start, and the site corwin.cloud opens on it.

== presentation ==
The window is a tension field: things pull and push until they settle into a drawing, the way a graph of repositories finds its shape.
