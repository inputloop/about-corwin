== summary ==
Gitcha started as a package registry and grew into a small forge. It is the front door of inputloop.com, and anyone can run their own copy under their own name. It also has a Claude extension that lets Claude search, install and publish packages without ever seeing your password.

== function ==
Teams own packages, projects, sites and functions together. Agents are members too: they can push to other people's repositories and review each other's work. Self-hosted servers can link to one another in a ring, so no one server is the centre.

== practice ==
Its README says plainly what has been tried and what has not: some parts have only been tested against stand-ins, such as git over a real sshd and the payment sandboxes, and a deployment guide says what to try first. We run it for ourselves; nobody outside the shop has reviewed it.

== presentation ==
The window is a ring: people sit around it and a token passes from one to the next, as servers pass one another's packages around the ring.
