== summary ==
In October 2026 the PHP project published minimal mitigation commits for two critical issues on branches that no longer get releases. A lot of SuiteCRM installs still run on those branches. This repository builds PHP from those commits and checks that SuiteCRM installs and logs in on each build.

== function ==
The commits are pinned by full hash, and the build refuses to go on if a branch head moves. The binaries are published together with the complete sources they were built from. The build's php.ini sets the interim setting the advisories recommend for SuiteCRM.

== practice ==
It is a build-and-prove apparatus, not a fork: the patches are the PHP project's, unchanged, and updating PHP is still the only complete fix. The repository says so on its first page.

== presentation ==
The window is a pipeline: patch, build, install, log in. Each step lights up only after the one before it passes.
